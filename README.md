Five quantiles of every Grand Theft Auto VI trophy's Exophase earn rate at the case's target, forecast from the reads the case carries: the tracked-players curve and the per-trophy earners curve are each extrapolated as a power law and divided.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
